## Build commands used

The installed Xcode lacked a bootable Simulator destination, so compilation was verified target-by-target against the Simulator SDK:

```sh
xcodebuild -project Pods/Pods.xcodeproj \
  -target Pods-SwingDeep \
  -configuration Debug \
  -sdk iphonesimulator26.4 \
  -arch arm64 \
  CODE_SIGNING_ALLOWED=NO build

xcodebuild -project SwingDeep.xcodeproj \
  -target SwingDeep \
  -configuration Debug \
  -sdk iphonesimulator26.4 \
  -arch arm64 \
  CODE_SIGNING_ALLOWED=NO build
```
